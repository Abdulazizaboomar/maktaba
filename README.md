# مكتبة الكتب — دليل مختصر

## إضافة كتاب (لصاحب المكتبة)
1. افتح صفحة الإدارة: `رابط-الموقع/admin.html`
2. أول مرة فقط: الصق مفتاح GitHub واضغط «حفظ والاتصال».
3. اكتب اسم الكتاب، واختر الغلاف (اختياري) وملف PDF، ثم اضغط «نشر الكتاب».
4. يظهر الكتاب في الموقع خلال دقيقة إلى ثلاث دقائق.

من نفس الصفحة: تعديل الاسم، تغيير الغلاف، الترتيب، الحذف، عنوان المكتبة، وتفعيل زر التحميل.

## طريقة احتياطية بدون صفحة الإدارة
ارفع ملف PDF مباشرة إلى مجلد `books` في GitHub، وسيظهر في الموقع تلقائياً.
ولو أردت غلافاً: ارفع صورة بنفس اسم الملف إلى مجلد `covers` (مثال: `books/kitab.pdf` و `covers/kitab.jpg`).

## ملاحظات
- يُفضّل ألا يتجاوز حجم الكتاب 30 ميجابايت حتى يفتح بسرعة على الجوال.
- إذا ظهرت رسالة «انتهت صلاحية المفتاح»: اضغط زر «إنشاء مفتاح جديد» في صفحة الإدارة.
- لا يحتاج الموقع أي تحديثات أو صيانة، وكل المكتبات والخطوط محفوظة داخله.

## الظهور في محركات البحث (v37)
- لكل كتاب صفحة نصية في مجلد `kitab/`، وفي `index.html` قائمة ثابتة بالكتب، ومعها `sitemap.xml` و `llms.txt`. كلها تتولد من `books.json` بالسكربت `tools/build_seo.py`.
- **تتحدث تلقائياً:** مع كل إضافة أو حذف أو تعديل من صفحة الإدارة، تشتغل مهمة «تحديث صفحات محركات البحث» في Actions (`.github/workflows/seo.yml`) وتحدّث الملفات.
- يدوياً: `python3 tools/build_seo.py`
- اسم المكتبة والمؤلف في `site.libraryName` و `site.authorName` داخل `books.json`.
- **لا تحذف ملف التحقق `google087c97577984bb59.html`** من جذر المستودع، لأن Google Search Console يتحقق منه.
- شارة «جديد» (v38): تظهر تلقائياً على أي كتاب يُضاف بعد الإطلاق، لمدة 45 يوماً، ويطلع أول القائمة.

## زر «الفهرس» و«الصفحات» في القارئ (v42)
- زر «الصفحات» يظهر في كل الكتب: مصغرات كل الصفحات للتنقل السريع، ومعاينة الصفحة أثناء سحب الشريط.
- زر «الفهرس» يظهر فقط للكتاب الذي له رقم صفحة فهرس في books.json، في الحقل `"toc"` (رقم صفحة الملف، مثل `"toc": 84`).
- عند إضافة كتاب جديد من صفحة الإدارة لا يُضاف الحقل تلقائياً، فيبقى زر الفهرس مخفياً حتى يُكتب رقم صفحة فهرسه في books.json.
- بعد القفز للفهرس يظهر زر «العودة إلى صفحة …» للرجوع لمكان القراءة.
